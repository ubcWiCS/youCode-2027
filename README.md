# youCode 2027 — Coming Soon Page

Landing page for youCode 2027, a 24-hour hackathon dedicated to fostering gender
inclusivity and breaking traditional norms in tech.

## Status

🚧 Coming soon page only — full site to follow.

## Tech Stack

- React
- Vite
- CSS Modules

## Getting Started

```bash
git clone https://github.com/ubcWiCS/youCode-2027.git
cd youCode-2027
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it locally.
